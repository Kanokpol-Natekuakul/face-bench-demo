ทดสอบสแกนหน้า

ทดลองเทียบหน้าและคัดกรองภาพจากจอหรือกระดาษ บน Supabase Edge Function ยังไม่ใช่ระบบเช็คอินจริง และไม่พิสูจน์เวลาที่ถ่ายรูป

ใส่ key

เปิดลิงก์จาก QR ที่ได้รับในเบราว์เซอร์นี้เพื่อใส่ key อัตโนมัติ ลิงก์เว็บปกติไม่มี key

ตั้งค่าทดลอง

เพิ่มเกณฑ์ = ผ่านยากขึ้น · ลด = ผ่านง่ายขึ้น ไม่ได้ทำให้โมเดลแม่นขึ้น
เปลี่ยนเกณฑ์แล้วตัดสินผลเช็คอินล่าสุดใหม่จากคะแนนเดิม ไม่ส่งรูปซ้ำ

การเตรียมภาพ (ขั้นสูง)

มีผลเมื่อส่งรูปใหม่เท่านั้น ไม่ประมวลผลรูปเก่าซ้ำ · ลดคุณภาพ JPEG อัตโนมัติได้ถึง 0.4 เพื่อให้ไม่เกินขนาดที่ตั้งไว้ การบีบภาพอาจเปลี่ยนคะแนนโมเดล
